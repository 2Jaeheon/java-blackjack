# java-blackjack

블랙잭 미션 저장소

# 프로그램 흐름

- 게임에 참여할 사람 이름을 입력
    - 입력 받은 이름을 , 로 파싱
    - 이름은 5자를 초과하는 경우 예외
    - 중복된 이름인 경우 예외
- 각 플레이어별 배팅
    - 배팅 금액은 100원 단위여야 한다.
    - 배팅 금액은 100원에서 100000 사이여야 함
- 덱을 생성
    - 카드의 숫자와 문양으로 52장의 카드를 생성
    - 덱을 만들 때 카드 52장을 섞는다.
- 초기 카드를 분배
    - 딜러에게 카드 2장 분배
    - 플레이어에게 카드 2장 분배
- 플레이어가 카드를 받을지 선택
    - 21 이하라면 카드를 받을 수 있다.
    - 21을 초과하면 카드를 받을 수 없다.
    - y를 입력하면 카드 한 장을 받는다.
    - n를 입력하면 다른 플레이어의 차례로 넘어간다.
    - 카드를 받았을 때 21 이상인 경우 다른 사람의 턴으로 넘어간다.
- 딜러가 카드를 받을지 말지 선택
    - 딜러의 카드가 16 이하인 경우 카드가 17이상이 될 때까지 카드를 뽑는다.
    - 딜러의 카드가 17 이상인 경우 카드를 뽑지 않는다.
- 경기 결과 계산 및 수익 계산
    - 딜러와 플레이어의 카드를 비교해서 더 큰 사람이 승리한다.
    - 플레이어가 이긴 경우 1배의 돈을 추가로 받는다.
    - 플레이어가 진 경우 돈을 잃는다.
    - 플레이어가 초기 카드가 21인 경우 1.5배의 돈을 추가로 받는다.
    -
- 결과 출력
    - 딜러의 결과 출력
    - 플레이어의 결과 출력
    - 최종 수익 출력

# 도메인 요구사항 정리

- Card
    - 숫자와 문양을 조합해 하나의 카드를 생성한다.
    - 카드는 자신의 기본 점수를 반환할 수 있다
    - 카드가 에이스인지 확인할 수 있다
    - A는 기본 11점이다.
- Hand(Cards)
    - 여러 장의 카드를 가진다.
    - 새로운 카드를 추가할 수 있다.
    - 현재 가진 카드의 총점수를 계산한다.
    - A가 없다면 모든 카드의 합을 반환한다.
    - A가 있다면 총합이 21를 초과하는 경우 A의 개수만큼 A를 1로 바꾼다.
- State(interface)
    - 새로운 카드를 뽑을 수 있는지 (isDrawable()) 상태를 반환한다.
    - 다음 상태를 반환한다.
    - 현재 상태의 카드들을 반환한다.
    - 현재 상태에 따른 수익률을 계산한다.
      <br><br>
    - Ready: 시작 상태
        - 처음 두 장의 카드를 받았을 때의 상태를 결정한다.
        - 2장의 합이 21 이면 Blackjack 상태가 된다
        - 2장의 합이 21 미만이면, Hit 상태가 된다.
    - Hit: 진행 상태
        - 카드를 한 장 더 뽑을 수 있다.
        - 카드를 한 장 더 뽑았을 때 총합이 21을 초과하는 경우 Bust 상태로 전이
        - 카드를 더 뽑지 않겠다고 선언하면 Stay 상태로 전이된다.
    - 종료 상태
        - 공통: 카드를 더 이상 뽑을 수 없다.
        - Bust: 21을 초과한 상태. 배당률은 무조건 -1배(패배)이다.
        - Stay: 21 이하에서 멈춘 상태. 승패 비교를 통해 배당률을 결정한다.
        - Blackjack: 처음 2장으로 21을 만든 상태. 승리 시 1.5배의 배당금을 받는다.

- 참여자(Participants)
    - 공통 (Participant)
        - 이름을 가진다.
        - 현재 상태의 상태를 가진다.
        - 카드 추가나 점수 계산 등의 행동을 상태 객체에게 위임한다.
    - Player
        - 배팅 금액을 가지고 있다.
        - 본인의 상태가 카드를 더 받을 수 있는 상태라면 카드를 뽑을지 선택할 수 있다.
    - Dealer
        - 딜러는 점수가 16 이하면 의무적으로 카드를 뽑는다.
        - 17 이상이면 카드를 뽑지 않는다.
- 배팅 및 수익계산
    - 배팅 금액은 100원 단위여야 한다.
    - 배팅 금액은 최소 100원, 최대 100,000원이어야 한다
    - 딜러와 플레이어의 최종 상태를 비교하여 플레이어의 최종 수익을 계산한다.
    - 딜러가 Bust일 때: Bust가 아닌 모든 플레이어는 승리한다.
    - 둘 다 Stay일 때: 점수가 더 높은 쪽이 승리한다.
    - 동점인 경우 무승부 처리한다.

- 덱 (Deck)
    - 생성 시 중복 없는 52장의 카드를 생성하고 섞는다.
    - 가장 위에 있는 카드 한 장을 뽑아서 반환한다.
    - 카드가 다 소진되었을 때 뽑으려 하면 예외가 발생한다.
